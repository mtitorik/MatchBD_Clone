# 💍 MatchBD — Matrimonial & Matchmaking Web Platform

A responsive, and high-performance matrimonial web platform built for Bangladesh and the global Bangladeshi diaspora (Probashi). Designed with modern aesthetics, asymmetrical Bento grids, interactive micro-UIs, and mobile-first responsiveness.

---

## ✨ Features

- **🎯 Interactive Bento Grid Architecture**:
  - **Step-by-Step Workflow**: 12-column responsive Bento grid with dynamic traits, compatibility gauges, mutual interest handshakes, and privacy toggles.
  - **Comprehensive Feature Grid**: Asymmetric 3-column Bento cards with real-time badges, privacy toggles, and global city tags.
- **🎨 Theme-Matched Color Palette**: Curated, harmonious gradient backgrounds across every section ensuring visual rhythm and zero monotony.
- **📱 Mobile-First & Ultra Responsive**: Fluid typography (`clamp()`), touch-friendly targets, and container query (`cqw`) units for phone, tablet, and desktop viewports.
- **🔒 Privacy & Verification**: Built-in visual demonstrations for photo blurring, NID screening, and double opt-in mutual consent.
- **🛍️ E-Commerce Gift Shop & Gift Cards**: Curated fine jewelry showcase and 6 tiered membership gift cards (Basic, Classic, Premium, Gold, Platinum, VIP) with elevated drop-shadows and tactile hover effects.
- **⚡ Core Web Vitals Optimized**: Zero external blocking scripts, `content-visibility: auto` for off-screen lazy rendering, asynchronous image decoding, and high-priority LCP preloads.

---

## 🛠️ Technology Stack

- **Markup**: Semantic HTML5 (SEO & Accessibility optimized)
- **Styling**: Vanilla CSS3 (Custom Design System, Flexbox, CSS Grid, Container Queries)
- **Interactions**: Vanilla JavaScript (High-performance `IntersectionObserver` scroll reveals, interactive mockups, and profile carousel)
- **Typography**: Google Fonts ([Quicksand](https://fonts.google.com/specimen/Quicksand))

## 🚀 Quick Start / Local Preview

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mtitorik/MatchBD_Clone.git
   cd MatchBD_Clone
   ```

2. **Run a local static server**:
   ```bash
   python3 -m http.server 8000
   ```

3. **Open in browser**:
   Navigate to [http://localhost:8000](http://localhost:8000).
